# Pijon

> Behavioral anti-cheat built for modern multiplayer games.

Pijon helps game developers detect unfair play through behavioral analysis instead of relying solely on traditional signature-based anti-cheat systems.

Our goal is simple: provide affordable, explainable anti-cheat technology for indie and mid-sized game studios.

---

## Current Status

🚧 This website is currently under active development.

The landing page serves as an introduction to the Pijon platform while the product is being built.

---

## Vision

Instead of detecting cheat software, Pijon focuses on detecting impossible player behavior.

Examples include:

- Aim assistance
- ESP / Wallhacks
- Ghosting
- Boosting
- Smurfing
- Griefing
- Match integrity analysis

Developers receive transparent confidence scores and detailed reports to support moderation decisions.
