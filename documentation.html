What is Pijon?

Pijon helps mobile game studios spot unfair play, understand what happened, and make better decisions without treating every unusual moment as proof of cheating.

It connects information from the game app, the studio’s own servers, and patterns across multiple matches. The result is a clear case a person can review, rather than a mysterious score with no explanation.

Think of Pijon as an investigation assistant

It watches for warning signs, gathers context, and points reviewers toward the strongest evidence. The studio remains in control of bans, appeals, and player communication.

The problem

Cheating rarely looks obvious

A player moving too quickly might be cheating, but they might also be experiencing lag. A sudden improvement in aim may be suspicious, or it may simply be a skilled player on a good day. Acting on one strange moment can punish innocent players.

Pijon asks three questions

  1. Can this game session be trusted?Was the game changed or running in an unsafe environment?
  2. Was this action possible?Could the movement, shot, or inventory change happen under the game’s rules?
  3. Does the behavior form a pattern?Does it remain unusual across enough matches and comparable players?
How it works

Three layers, one evidence trail

Core checks the environment

Core looks for signs that the game build, device, or session has been altered. It helps decide whether later match information can be trusted.

Gate checks live actions

Gate compares actions with rules known by the game server. If an action is physically impossible, it can be stopped before it affects the match.

Trace studies behavior over time

Trace looks for repeated patterns involving aim, awareness, skill changes, or linked accounts. This is Pijon’s main layer for finding evidence that one match cannot prove.

Fair decisions

From signal to human review

A signal is a reason to look closer, not an automatic accusation. Pijon groups related signals with match context and explains why a case became more or less suspicious.

StageWhat it means
ObserveSomething unusual happened, but more context is needed.
ReviewEnough related evidence exists for a trained person to inspect.
DecideThe studio confirms, dismisses, or continues observing the case.
AppealThe player can challenge an action according to the studio’s policy.
False positives matter

Pijon is designed to reduce confidence when data is incomplete and to keep serious decisions reviewable. No anti-cheat system should promise perfection.

For studios

What a studio can do with Pijon

  • See whether protection is working across game versions and devices.
  • Review the strongest cases first instead of searching raw logs.
  • Understand which signals contributed to a recommendation.
  • Choose review-first or carefully automated policies.
  • Keep an audit history of evidence, decisions, and team actions.
  • Measure review volume and false-positive indicators over time.

Technical integration guides, service credentials, policy controls, and detailed signal information are available only to authenticated studio members.

For players

What Pijon should and should not do

Pijon should help studios protect fair matches while collecting only the information needed for game integrity. It should not secretly decide punishments without studio policy, reveal private detection methods, or remove a meaningful appeal path.

  • The game studio, not Pijon alone, decides what action to take.
  • Unusual play is not automatically cheating.
  • Evidence should be retained only as long as the studio’s policy requires.
  • Players should be able to find the studio’s support and appeal process.
