Core

Core checks whether the game, device and session can be trusted before match data becomes evidence. It looks for tampering, unsafe environments and altered builds.

Build Integrity Device Trust Memory Tool Detection Root/Jailbreak Signals Session Validation Runtime Memory Checks Emulator Signals Signature Drift Integrity Receipts

Gate

Gate lives on the game server and checks whether player actions are physically possible before they affect the match. Impossible speed, fire rate or hit data is rejected immediately.

Movement Limits Fire-Rate Rules Hit Validation Server-Side Enforcement

Trace

Trace studies behavior over many matches to find patterns a single moment cannot prove. It turns suspicious aim, awareness and account links into reviewable evidence.
